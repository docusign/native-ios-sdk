# docusign-sdk-sample-swift
DocuSign Native iOS SDK - Sample App in Swift

Requirements
=============
Docusign SDK v4.4.0 supports
* iOS 15.0 or later
* Xcode 16.0 or later

Install
=============
* Open `docusign-sdk-sample-swift.xcodeproj` in Xcode.
* Xcode will automatically resolve Swift Package Manager dependencies (`native-ios-sdk` `4.4.0` and `SVProgressHUD`).
  * To manually resolve or update packages in Xcode, select **File → Packages → Resolve Package Versions** (or **Update to Latest Package Versions**).
* Update your developer sandbox credentials in `docusign-sdk-sample-swift/Managers/ProfileManager.swift`, then build and run.
* Please see the [Getting Started](https://developers.docusign.com/docs/mobile-sdks/ios-sdk/) section on the **Developer's Site** for more details.
